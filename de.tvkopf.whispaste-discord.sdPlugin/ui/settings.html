WhisPaste → Einstellungen → „Local Automation API" aktivieren, dann Port und Token hier eintragen.
Discord → Developer-Portal → New Application → OAuth2 → Redirect http://localhost eintragen, Client-ID und Secret hier eintragen. Beim ersten Start erscheint im Discord ein „Autorisieren"-Dialog.
Regeln: Während des Diktats wird Discord gemutet. Danach passiert je nach Modus …
„Wiederherstellen" stellt exakt den Zustand von vor dem Diktat wieder her (empfohlen).
Tipp: Die Status-Taste auf dem Deck zeigt WhisPaste/Discord-Zustand und repariert bei Druck die Discord-Verbindung (inkl. Neu-Autorisierung).
